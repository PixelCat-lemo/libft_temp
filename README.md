Libft
Description

Libft is a 42 project with the objective of recreating standard C library 
functions and implement additional utilities. The final goal is to improve 
the understanding of C, memory management, pointers, linked lists and
other base concepts of C.

Instructions

Compile the library:
bash
	make
This generates libft.a.

Available Makefile rules:

	make: Compile the library.
    make clean: Remove object files.
    make fclean: Remove object files and the library.
    make re: Recompile everything.

To use Libft, include libft.h and link libft.a when compiling your C program.
